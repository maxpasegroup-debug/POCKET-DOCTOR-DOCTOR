# Doctor launcher artwork

`doctor-app-icon.png` is the original image supplied by the user for the Doctor
app icon. It is retained without modification. Native launcher resources are
generated by `scripts/generate-app-icons.ps1` using aspect-preserving scaling and
narrow edge padding to fit square icon canvases. No artwork or lettering is cropped.

Android already references `@mipmap/ic_launcher`; iOS already references the
AppIcon asset catalog. These native resources do not need a Flutter asset entry.
